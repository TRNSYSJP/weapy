# CSVファイルとType99ファイル比較スクリプト

## 概要
CSVファイルとType99形式の天気データファイルを比較し、データの相関係数と統計情報を計算するツールです。

【注意】<br>
CSV,Type99形式には、拡張アメダス気象データが含まれるためリポジトリに登録していません。<br>
比較対象のファイルはDataNavi8、スクリプト（conv_wea2_type99.py）でWEA2形式から作成してください。


## ファイル構成
- `compare_files.py` - 比較スクリプト（メイン）
- `run_all_comparisons.bat` - 全ファイル一括比較バッチファイル

### CSVファイル
- 気象データシステム、DataNavi8 より作成
- 拡張アメダス気象データ、標準年2020年度版より、Type99で使用する項目をDataNaviからコピー＆ペーストでExcelへ貼り付けて作成
- 値の並び順、[]は単位
  - 気温[C]、相対湿度[%]、全天日射量[MJ/(m2h)]、大気放射量[MJ/(m2h)]、風向[-]、風速[m/s]、降水量[mm]、日照時間[h]
- 風向は22.5を乗じると角度[deg]（Type99の風向になる）

### type99ファイル(.99)
- 1行目から19行目はヘッダー
- 20行目以降がデータ
- データはカラム順に以下の値が含まれています
  - 気温[C]、相対湿度[%]、全天日射量[W/m2]]、大気放射量[W/m2]]、風向[deg]、風速[m/s]、降水量[mm]、日照時間[h]



## 使用方法

### 1. 単一ファイルペアの比較

```bash
# デフォルト値（えりも岬）
python compare_files.py

# 特定のファイルを指定
python compare_files.py "1480-えりも岬.csv" "ea2020_wea2_1480_ERIMOMISAKI.99"
python compare_files.py "3630-東京.csv" "ea2020_wea2_3630_TOKYO.99"
python compare_files.py "1930-大潟.csv" "ea2020_wea2_1930_OGATA.99"
python compare_files.py "4100-野辺山.csv" "ea2020_wea2_4100_NOBEYAMA.99"
python compare_files.py "6180-笠岡.csv" "ea2020_wea2_6180_KASAOKA.99"
```

### 2. 全ファイルペアの一括比較

バッチファイルを実行：
```bash
run_all_comparisons.bat
```

または、コマンドラインから直接実行：
```bash
.\run_all_comparisons.bat
```

Pythonスクリプトだけで一括比較することもできます：
```bash
python compare_files.py --all
```

## 出力内容

### コンソール出力
- 相関係数の計算結果（全8項目）
- 詳細な統計情報（平均値、標準偏差、完全一致率など）
- 比較結果の結論

### ファイル出力
- `comparison_results.txt` - `run_all_comparisons.bat` 実行時の詳細結果
- `comparison_results_all.txt` - `python compare_files.py --all` 実行時の詳細結果

## データ項目

比較対象の8項目：
1. **気温** [°C] - 完全一致
2. **相対湿度** [%] - 完全一致
3. **全天日射量** [W/m²] - 単位変換後（MJ/(m²h) → W/m²）
4. **大気放射量** [W/m²] - 単位変換後（MJ/(m²h) → W/m²）
5. **風向** [°] - 単位変換後（無次元 × 22.5）
6. **風速** [m/s] - 完全一致
7. **降水量** [mm] - 完全一致
8. **日照時間** [h] - 完全一致

## 単位変換

**全天日射量・大気放射量の換算係数：**
```
1 MJ/(m²h) = 1000 J ÷ (m² × 3.6 s) = 277.78 W/m²
```

**風向の換算係数：**
```
風向[度] = 風向[無次元] × 22.5
```

## ファイル形式

### CSVファイル
- ヘッダーなし
- 1行＝1時間分のデータ
- 8760行（24時間 × 365日）
- データ列順：気温, 相対湿度, 全天日射量, 大気放射量, 風向, 風速, 降水量, 日照時間

### Type99ファイル
- 1～19行目：ヘッダー情報
- 20行目以降（`<data>`行の次）：データ
- 各行に8列のデータを含む
- データ列順：気温, 相対湿度, 全天日射量, 大気放射量, 風向, 風速, 降水量, 日照時間

## 比較結果の解釈

### 相関係数
- **1.0に近い** → 2つのデータの変化の傾向が同じ
- 定数倍や一定のずれがあっても1.0になるため、相関係数だけではデータが同一かどうかは判定できません

### 差の統計
- **平均差** - 各データポイントの平均的なズレ
- **最大差** - 最もズレが大きいデータポイントの差
- **完全一致率** - 差が1e-6以下のデータの割合

> **判定基準**：最大差が丸め誤差（全天日射量・大気放射量は単位変換と小数点3桁の丸めにより0.001程度）以下であれば、2つのファイルは実質的に同一のデータです。完全一致率は、丸め誤差の出る全天日射量・大気放射量以外で100%になります。

## トラブルシューティング

### ファイルが見つからないエラー
- CSVファイルと Type99ファイルが同じフォルダに存在することを確認してください

### モジュール not found エラー
- 必要なライブラリをインストール：`pip install pandas numpy`

### エンコーディングエラー
- CSVファイルが UTF-8 エンコーディングで保存されていることを確認してください
